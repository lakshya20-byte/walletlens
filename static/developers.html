WalletLens API

Let your wallet, dApp or bot warn users about risky token approvals on Monad. Two read-only endpoints, JSON in and out.

1. Check a spender before the user signs

GET /api/v1/check?spender=0x...&unlimited=true

curl "https://YOUR-URL/api/v1/check?spender=0x1111111111111111111111111111111111111111&unlimited=true"
{
  "version": "1",
  "spender": "0x1111...1111",
  "verdict": "review",
  "reason": "A contract is asking for an unlimited allowance. ...",
  "checked": ["whether the spender address has contract code"],
  "limitations": "Heuristic. Covers ERC-20 approvals only. ..."
}

verdict is one of warn (plain wallet), review (contract, unlimited), no_flag, unclassified. There is deliberately no "safe" verdict.

const r = await fetch("https://YOUR-URL/api/v1/check?spender=" + spender + "&unlimited=true");
const v = await r.json();
if (v.verdict === "warn") {
  showWarning(v.reason); // ask the user to confirm before signing
}

2. Scan a wallet's active approvals

GET /api/v1/scan/{address}

{
  "version": "1",
  "chain": "monad-mainnet",
  "address": "0x...",
  "risk_level": "medium",
  "scanned_blocks": 112532831,
  "findings": [{
    "id": "wl-1",
    "severity": "medium",
    "title": "Unlimited approval to a contract",
    "description": "The contract 0x0000...10e2 can spend any amount of 5 tokens. ...",
    "evidence": { "tx_hash": "0x...", "explorer_url": "https://..." },
    "source": "On-chain ERC-20 Approval event logs (Envio HyperSync, RPC fallback)",
    "confidence": { "approval_exists": "high", "risk_judgement": "heuristic" },
    "limitations": "Heuristic. Covers ERC-20 approvals only. ..."
  }],
  "summary": "...",
  "summary_written_by": "rules"
}

risk_level is high, medium or low. High is reserved for an unlimited approval to a plain wallet. Every finding links to the transaction that created the approval.

Limits and honesty

Rate limited per IP. Results are cached for 5 minutes. Data comes from Envio HyperSync with an RPC fallback that only sees recent blocks, so a fallback scan covers far less history. WalletLens does not check token reputation, known-malicious address lists, NFT approvals or transaction history, and "low" never means "safe".
